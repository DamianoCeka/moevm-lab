# Generated visual assets

The two raster illustrations in this directory were generated specifically for
the MoEVM Lab landing page on 2026-08-17 with OpenAI's built-in image generation
tool. They contain no third-party logos, characters, or source artwork.

## `moevm-memory-flow-hero.png`

Prompt summary: a panoramic, original 3D technical visualization of expert
payload cubes moving from NVMe through pinned-memory staging to a GPU, using a
solid cyan demand path and a dotted coral lookahead path. Dark research-lab art
direction; no text, logos, people, mascots, or copyrighted characters.

## `sparse-expert-routing.png`

Prompt summary: an original 3D visualization of a sparse Mixture-of-Experts
layer with many inactive expert modules and a small selected set illuminated in
cyan and coral. Dark research-lab art direction; no text, logos, people,
mascots, or copyrighted characters.
